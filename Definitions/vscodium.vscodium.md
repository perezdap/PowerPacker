## Pre-Install
Close VSCodium if it is currently running.

## Install
Install VSCodium using the silent installer.

## Post-Install
Remove the Desktop shortcut created by the installer.

## Detection
Check for VSCodium installation by checking the registry for the machine-wide uninstall entry.

## Uninstall
Uninstall VSCodium using the silent uninstall command, you can look at silentinstallhq.com for information on many install/silent install commands
